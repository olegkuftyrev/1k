# Dashboard

## URL

`app.ordina.one/dashboard`

Redirected here automatically after successful login.

## Layout

Mobile first. Single-column on mobile, grid on wider screens.

The dashboard shows only the tools the current user has access to. A user without CRM access does not see the CRM tile. No locked/greyed-out tiles — if you don't have access, the tile doesn't appear.

## Tool tiles

Each tool is represented as a card/tile. Clicking a tile opens the tool in a new browser tab.

### Current tools

| Tile | Destination | Access |
|------|-------------|--------|
| Notion | notion.so workspace | Per user |
| CRM | crm.ordina.one | Per user |

### Future tools

Additional tiles will be added as new tools are onboarded. Each new tool is a new tile with its own access flag.

## Notifications

Notifications will be shown on the dashboard. Scope and source TBD.

## Navigation

Minimal. The dashboard is the primary screen. No deep navigation needed at this stage.

Top bar contains:
- Company logo / wordmark
- User avatar or initials
- Logout action
