# Glossary

| Term | Definition |
|------|------------|
| **AP** | Asset Protection — identifying and stopping financial losses caused by theft, shrinkage, fraud, or untracked leaks. |
| **Core document** | Our standard version of a document, not yet adapted for any specific client. Prefixed with `cf_`. |
| **Client file** | A version of a core document adapted for a specific client. Prefixed with the client's name or abbreviation (e.g., `cookie_`). |
| **cf_** | Prefix for core documents. Stands for "consulting firm" — placeholder until the company name is finalized. |
| **SOP** | Standard Operating Procedure — a written step-by-step instruction for a specific task or process. |
| **Operational Elevation Package** | Our productized service: a library of approximately 50 SOPs, adapted for the client's business and implemented with their team. |
| **[NEEDS WORK]** | A marker at the top of a document section indicating the content has not been written or finalized yet. |
