# ORDINA

## Safe Access & User Management Procedure

### Summary

Safe access is restricted to authorized associates only.

User access must be properly assigned, reviewed, updated, and removed to protect company funds and maintain accountability.

---

# Purpose

Establish procedures for:

- Safe access.
- User management.
- Code administration.
- Access reviews.
- User removal.
- Password security.

This procedure applies to all company safes and secure cash storage systems.

---

# Access Authorization

Only authorized associates may receive safe access.

Access levels should be assigned based on:

- Position.
- Job responsibilities.
- Operational needs.

Managers are responsible for approving all access.

---

# Opening the Safe

Authorized users may access only the sections of the safe assigned to them.

Associates should:

1. Enter their individual credentials.
2. Wait for any required time delay.
3. Open only the authorized compartment.
4. Secure the safe immediately after use.

Safe doors should never remain open while unattended.

---

# Creating New Users

When an associate requires access:

- Management must authorize access.
- A unique user profile must be created.
- Temporary credentials must be changed immediately.
- Users must create their own confidential code.

Access should only be granted after appropriate training.

---

# User Responsibilities

Each authorized user is responsible for:

- Protecting their access code.
- Keeping credentials confidential.
- Logging in under their own account.
- Reporting security concerns.

Sharing codes is strictly prohibited.

---

# Access Reviews

Management should periodically review:

- Active users.
- Access levels.
- Disabled users.
- Former associates.

Access should match current job responsibilities.

---

# Disabling User Access

User access should be disabled immediately when:

- An associate transfers.
- Employment ends.
- Responsibilities change.
- Security concerns arise.

Inactive accounts should not remain active.

---

# Removing Users

Managers must remove access promptly following:

- Termination.
- Resignation.
- Transfer.
- Leave of absence when appropriate.

Delayed removal creates unnecessary security risks.

---

# Code Changes

Safe codes should be changed:

- At regular intervals.
- After suspected code sharing.
- Following security incidents.
- After management turnover.
- When unauthorized access is suspected.

New codes must remain confidential.

---

# Dual Access Procedures

When multiple compartments require access:

- Follow manufacturer procedures.
- Observe required delays.
- Maintain accountability.
- Secure each compartment after use.

---

# Management Responsibilities

Managers are responsible for:

- Granting access.
- Reviewing users.
- Removing inactive accounts.
- Maintaining security.
- Protecting company assets.

---

# Prohibited Practices

Associates may not:

- Share access codes.
- Use another person's credentials.
- Leave the safe open.
- Leave written codes near the safe.
- Allow unauthorized access.
- Delay removing inactive users.

Violations may result in corrective action.

---

# Guiding Principle

Every user.

Every access.

Every transaction.

Accountability protects both the associate and the business.
