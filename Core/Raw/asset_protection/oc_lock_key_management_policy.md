# ORDINA

## Lock & Key Management Policy

### Summary

Locks, keys, and access credentials protect our associates, guests, cash, and property.

Effective key management ensures that only authorized individuals have access to company facilities and secure areas.

Every key must have an owner.

Every access point must have accountability.

---

# Purpose

Establish standards for:

- Exterior door security
- Key control
- Access accountability
- Lost key procedures
- Lock replacement
- Access management

This policy applies to all company facilities.

---

# Exterior Security

All exterior doors must remain secure when not actively in use.

Requirements:

- Back doors remain locked at all times.
- Secondary entrances should remain secured.
- Vulnerable entrances may be locked during low-volume periods.
- Roof access points must remain secured.
- Exterior locks must function properly.

Defective locks should be repaired immediately.

---

# Access Control

Access should only be provided to associates who require it to perform their duties.

Access may include:

- Building keys.
- Electronic credentials.
- Alarm codes.
- Safe access.
- Security systems.

Unauthorized access is prohibited.

---

# Key Issuance

Managers may issue keys only to authorized associates.

Each issued key should be documented.

Records should include:

- Associate name.
- Key identification.
- Date issued.
- Date returned.

Associates accepting keys assume responsibility for their security.

---

# Key Accountability

All keys must remain secure.

Associates may not:

- Share keys.
- Duplicate keys.
- Lend keys.
- Leave keys unattended.
- Store keys in unsecured areas.

Work keys should remain separate from personal keys whenever possible.

---

# Key Storage

Unassigned keys should be stored securely.

Managers should:

- Limit access.
- Maintain records.
- Protect master keys.
- Control spare keys.

Keys should never be left in open work areas.

---

# Associate Separation or Transfer

When employment ends or responsibilities change:

- Keys must be returned immediately.
- Access credentials must be removed.
- Alarm access must be deleted.
- Safe access must be disabled.

Former associates should not retain access to company property.

---

# Lost Keys

If a key is lost:

1. Conduct an immediate search.
2. Notify management.
3. Assess the security risk.
4. Rekey or replace locks if necessary.
5. Update access records.

Management should act quickly to protect company assets.

---

# Electronic Access

Electronic credentials, alarm codes, and access numbers:

- Must remain confidential.
- Must not be shared.
- Should be changed when security concerns arise.
- Should be removed immediately when no longer needed.

Every user should have their own credentials.

---

# Management Responsibilities

Managers are responsible for:

- Issuing access.
- Maintaining records.
- Recovering keys.
- Protecting credentials.
- Responding to lost keys.
- Maintaining physical security.

---

# Prohibited Practices

Associates may not:

- Share keys or codes.
- Duplicate company keys.
- Leave keys unattended.
- Prop open secured doors.
- Store keys in unsecured locations.
- Retain keys after separation.

Violations may result in corrective action.

---

# Guiding Principle

A lock only works when access is controlled.

Every key must have an owner.

Every access point must have accountability.

Security begins with controlling who can enter.
